# My Budget Tracker

## Project Description
My Budget Tracker is a simple web application designed to help users organize and track their daily expenses.

## Week 2 Features
- Expense form with name and amount inputs.
- Category selection using a dropdown menu.
- Expense table with sample records.
- Budgeting Tips video using an HTML iframe.
- Interactive instructions using HTML details and summary.
- Advanced CSS selectors and hover effects.
- Styled input fields and buttons.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Live Server

## Project Structure
- `index.html` – Contains the website structure.
- `style.css` – Contains the website styling.
- `README.md` – Project documentation.
